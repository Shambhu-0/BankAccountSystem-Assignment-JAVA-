# Bank Account Management System

## About the Project

This project is a simple **Bank Account Management System** developed using Java as part of my Java OOP assignment.

The program demonstrates the use of classes, objects, constructors, and methods to manage basic banking operations. It allows users to create bank accounts, deposit money, withdraw money, check their balance, and display account details.

## Features

- **Account Creation:** Creates bank accounts using a parameterized constructor.
- **Deposit Money:** Adds money to the account balance.
- **Withdraw Money:** Withdraws money if sufficient balance is available.
- **Check Balance:** Displays the current available balance.
- **Display Account Details:** Shows the account number, account holder's name, and current balance.
- **Independent Accounts:** Each account maintains its own separate balance.

## OOP Concepts Used

This project demonstrates the following Object-Oriented Programming concepts:

- **Classes and Objects:** The `BankAccount` class is used to create multiple bank account objects.
- **Constructors:** A parameterized constructor initializes account details.
- **Encapsulation (Basic):** Account-related data and operations are grouped within the `BankAccount` class.
- **Instance Variables:** Each object maintains its own account details and balance.
- **Methods:** Separate methods are implemented for deposit, withdrawal, balance checking, and displaying details.

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/Shambhu-0/BankAccountSystem-Assignment-JAVA-.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Bank-Account-Management-System
   ```

3. Compile the Java files:

   ```bash
   javac BankAccount.java Main.java
   ```

4. Run the program:

   ```bash
   java Main
   ```
